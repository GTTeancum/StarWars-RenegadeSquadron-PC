# 0.9.1 Linux build (Ubuntu 26.04 x86-64)

This is a native Linux ELF player using Vulkan, built locally with Clang 21 on Ubuntu 26.04 in WSL2. It is not a universal Linux/AppImage build: it requires glibc 2.43+, libstdc++ providing GLIBCXX_3.4.32, FFmpeg 8 runtime libraries, and a Vulkan 1.1 driver. Ubuntu 22.04/24.04 and older SteamOS installations are not supported by this binary.

## Setup

On Ubuntu 26.04, install the runtime dependencies if missing:

```sh
sudo apt install libavcodec62 libavformat62 libavutil60 libswresample6 libswscale9 libstdc++6 libvulkan1
```

Use your distribution's graphics-driver packages for hardware Vulkan support. SDL2-compat, SDL3, and libXss are bundled under `lib`, with their license notices under `licenses`. Other desktop/audio dependencies come from the host system. No compiler or Vulkan SDK is required to play.

1. Extract `RenegadeSquadronPC-0.9.1-linux-ubuntu26.04-x86_64.tar.gz` into a writable folder.
2. Put your own US ULUS10292 game ISO beside `RenegadeSquadron`, or reuse `data/PSP_GAME` from an extracted disc.
3. Run `./Play-RenegadeSquadron.sh` from a terminal. The first launch automatically extracts the ISO when needed. `./Play-RenegadeSquadron.sh --prepare-data` performs preparation only.

Preserve `SAVEDATA`, `data`, and custom texture packs when upgrading. Original game disc data is not included. Existing PC menu overrides from the Windows 0.9.1 package are included. Vulkan is the default and only hardware-renderer API on Linux; DirectX 12 is Windows-only.

## Tested scope

The local WSL2 installation exposed Mesa llvmpipe (CPU software Vulkan). All three Vulkan pixel/presentation tests passed. A 1280x720, 4x MSAA replay reached Hoth gameplay and exited cleanly at vblank 2600. Difficulty, team-selection, and gameplay screenshots were inspected, including textured characters, AT-AT, terrain, sky, and HUD. Audio capture contained 45.4 seconds of non-silent stereo PCM.

This does not establish Linux hardware-GPU performance. Visible-window interaction, physical controls, and speaker playback remain untested. Enhanced per-pixel lighting, normal maps, sun shadows, and bloom are not implemented in the Vulkan backend. Existing module/network and sceIoDevctl diagnostics did not prevent the tested match from loading.

The Linux source is based on commit `0f01075` (plus packaging documentation). The original `v0.9.1` tag identifies the earlier Windows release; it has not been moved. See the Linux source commit linked in the GitHub release notes for the portability changes. The package includes a manifest and has a separate SHA-256 checksum.
