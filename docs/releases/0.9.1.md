# 0.9.1 Hotfix

Native Vulkan is now the default renderer. This release also fixes missing textures on 3D models in the new Vulkan path and adds automatic first-run ISO extraction.

## Install or upgrade

1. Extract `RenegadeSquadronPC-0.9.1.zip` into a writable folder.
2. Put your own US game ISO (ULUS10292) beside `RenegadeSquadron.exe`. The first launch extracts it into `data/PSP_GAME`; subsequent launches reuse the extracted data. An existing `data/PSP_GAME` folder also works. The ISO and original disc data are not included.
3. Run `RenegadeSquadron.exe`. Windows 10/11 x64 and a Vulkan 1.1-capable graphics driver are required for the default renderer.

When upgrading, preserve your `SAVEDATA`, `data`, and optional texture packs. Back up any customized INI before replacing it with the new defaults. To select the previous renderer, set `Backend=DirectX12` under `[Rendering]` in `RenegadeSquadron.ini`.

The optional [0.9b HD texture pack](https://github.com/GTTeancum/StarWars-RenegadeSquadron-PC/releases/tag/v0.9b) remains available separately. It has not been revalidated with Vulkan and may cause stuttering. Existing PC menu overrides from 0.9b are retained in this package.

## Changes

- Native Vulkan device, swapchain, texture upload/cache, depth/stencil, blending, fog, framebuffer feedback, and MSAA support. No D3D12-to-Vulkan translation layer is used.
- Fixed double normalization of 3D texture coordinates, which made terrain, vehicles, and characters appear untextured. Added a textured model regression test.
- Fixed redundant texture reuploads within a frame.
- Added automatic ISO extraction and game identity validation, plus `--prepare-data` for extraction without starting the game.
- Added repository-local Vulkan dependency restoration, shader compilation, and renderer tests; fixed the code-generation script's early exit.

## Validation and current limits

- All three native Vulkan test cases pass (single-sample, MSAA, and hidden-window presentation).
- A bounded headless smoke test on Radeon 780M reached Hoth gameplay at 1280x720 with 4x MSAA. Menu, team-selection, and gameplay captures were visually inspected after the texture fix; the run exited cleanly.
- The packaged executable was checked for default Vulkan startup. Audio capture was non-silent. Speaker playback, physical controls, and visible-window interaction were not tested.
- Vulkan currently uses original GE vertex lighting. Enhanced per-pixel lighting, normal maps, sun shadows, and bloom remain DirectX 12-only and are disabled in the bundled Vulkan defaults.
- Vulkan performance is not finalized; the earlier DirectX 12 performance figures do not describe this build. This build uses MSVC `/O2 /Ob0` for translated game code.
- Full-game coverage and rare blend modes remain unverified. An existing `sceIoDevctl(0x80010016)` diagnostic also appears on DirectX 12 and did not prevent the tested match from loading.

The ZIP is accompanied by a SHA-256 checksum and contains a per-file manifest.
